# Sources and adaptation

This skill adapts the reviewed local `godot-web-game-dev` architecture and asset guidance into a self-contained native desktop workflow. It does not depend on installing that skill.

Original reviewed source: [vl4dt/godot-skills](https://github.com/vl4dt/godot-skills/tree/1ae280d35f2cc3931d4d8eb63f4bac82d6acf4a0), commit `1ae280d35f2cc3931d4d8eb63f4bac82d6acf4a0`. The upstream copyright and MIT permission notice remain in [LICENSE](../LICENSE). Upstream hooks, tracking tools, MCP bridge, unverified examples, and mandatory execution workflows are not included.

Platform guidance was prepared against official Godot documentation on 8 October 2026. Entry points include [renderer comparison](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html), [Windows export](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_windows.html), [Linux export](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_linux.html), [macOS export](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_macos.html), [quit handling](https://docs.godotengine.org/en/stable/tutorials/inputs/handling_quit_requests.html), and [3D optimization](https://docs.godotengine.org/en/stable/tutorials/performance/optimizing_3d_performance.html).

Select the actual project release when applying documentation. `stable` can move and does not establish installed tools or export-template compatibility. This instruction-only skill includes no executable helpers and makes no claim of runtime validation.
