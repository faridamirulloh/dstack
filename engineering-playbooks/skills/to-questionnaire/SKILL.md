# To Questionnaire

Interview the user only about what they know: who will receive it and what the user needs back.

1. Identify the recipient's role, expertise, relationship, and relevant context.
2. Identify the decisions or facts the answers must unlock.
3. Write the questionnaire to the requested path, or `to-questionnaire-<topic>.md` in the current workspace when no path is given.
4. Order questions by importance and group longer questionnaires by theme. Ask one idea per question, add an answer stub, and explain why only when a question could be misread.

Include title, purpose, sender and recipient, context, how to answer, themed questions, and an "Anything else?" prompt. Cover every required decision. Encourage partial answers and explicit uncertainty.
