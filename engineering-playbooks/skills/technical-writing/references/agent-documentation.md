# Agent Documentation

Agent documentation is navigation plus constraints, not a replacement for the codebase.

## Context pointers

Point to the authoritative file, symbol, command, schema, or example and explain why it matters. Copy only stable facts required before the pointer can be followed.

## Progressive disclosure

Keep the entrypoint small:

1. Trigger and intended outcome.
2. Non-negotiable boundaries.
3. Default workflow.
4. Links to optional references for variants and edge cases.

## Instruction quality

Prefer observable verbs: read, compare, run, write, verify, report. Name conditions for branching. Distinguish advice from requirements, and never imply access to a tool or permission the host may not provide.

For skills, keep `SKILL.md` focused on routing and execution. Put large templates, rubrics, and examples in nearby references and link them directly.
