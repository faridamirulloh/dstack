# Prototype

Use for a disposable experiment that answers a design or behavior question.

1. Write the decision the prototype must inform and the observation that would answer it.
2. Choose the smallest isolated artifact: a scratch file, temporary directory, minimal UI, or focused logic probe.
3. Build only enough to exercise the uncertain behavior. Explore structurally distinct alternatives when comparison is the point.
4. Run the experiment and record observations, limitations, and misleading shortcuts.
5. Recommend the next step: discard, revise the design, or start a separately scoped production implementation.

Keep prototype code out of production paths unless the user explicitly promotes it and the production route adds the missing quality, safety, and verification work.
