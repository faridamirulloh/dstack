# Error Tracking

Use an available error tracker to connect defensive or corrective code with production failures.

Search by exception, stack frame, symbol, release, environment, trace ID, and dates near the change. Inspect representative events, frequency, affected versions, first and last seen times, linked commits, and resolution notes.

Record the issue URL, filters, event window, and relevant stack evidence. A matching error supports the problem statement; a resolution date near a code change does not by itself prove that change fixed it.
