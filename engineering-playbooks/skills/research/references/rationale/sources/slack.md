# Team Chat

Use team chat only when a connected source is available and the user's request authorizes access.

Search exact symbols, error strings, feature names, ticket IDs, and authors near the change window. Read surrounding messages and linked threads; a single search-result snippet strips context. Prefer messages that state a decision and reason, especially when corroborated by code, a review, or a document.

Quote sparingly and link to the message. Treat recollection, speculation, jokes, and abandoned proposals as weak evidence. Do not expose private conversation or personal data beyond what the answer requires.
