# Incident and Postmortem Records

Search incident systems, postmortems, issues, reviews, observability, and code for a shared time window, service, error, or remediation phrase.

Build a short timeline: impact, detection, cause, containment, permanent remediation, and follow-up. Link each step to its primary record. The strongest rationale connects the code change to a named corrective action and verifies the affected behavior.

Do not infer causation from dates alone. Distinguish the incident's direct remediation from later hardening, cleanup, or unrelated changes shipped nearby.
